# Recipe Dashboard Agent Instructions

- This repository is a standalone product. Do not add Fleet Console navigation,
  imports, runtime dependencies, or portfolio concerns.
- Do not deploy, publish, commit, or push unless explicitly requested.
- Do not touch secrets or environment files.
- Astro is the sole owner-approved production dependency. Explain and obtain
  approval before adding anything else.
- Read `PRODUCT.md`, `DESIGN.md`, and `PROJECT_STATUS.md` before broad work.
- Use OpenSpec for non-trivial product changes.
- Preserve the source/estimate distinction and never fabricate missing recipe
  quantities.
- Run `npm test` and `npm run check` after behavior changes.
